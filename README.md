# @nmaass/research-ui

Shared, router-agnostic React primitives and CSS tokens for the Number Research family of applications.

## Install from GitHub

```json
{
  "dependencies": {
    "@nmaass/research-ui": "github:NMaass/Chord-Research#research-ui-v0"
  }
}
```

```tsx
import "@nmaass/research-ui/theme.css";
import { ResearchHeader, ResearchNav, ResearchShell } from "@nmaass/research-ui";
```

The package intentionally excludes domain-specific components such as chord controls, shape drawing, pizza visualizations, and gacha mechanics.
